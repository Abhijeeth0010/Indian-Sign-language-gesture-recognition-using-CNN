🧠 Indian Sign Language Gesture Recognition using CNN

This project focuses on recognizing Indian Sign Language (ISL) hand gestures using deep learning techniques to support inclusive and accessible communication.

The model is built using Convolutional Neural Networks (CNN) with a ResNet50 architecture, trained on an ISL image dataset. The system performs image preprocessing, model training, and evaluation to accurately classify different hand gestures.

🚀 Technologies Used

Python

TensorFlow & Keras

Convolutional Neural Networks (CNN)

ResNet50

NumPy, Matplotlib

Jupyter Notebook

📊 Results

Achieved 93.66% accuracy on the ISL dataset after model tuning and evaluation.

📌 Key Highlights

Implemented an end-to-end ML pipeline: preprocessing → training → evaluation

Used transfer learning with ResNet50 for improved performance

Focused on clarity, reproducibility, and learning core deep learning concepts

📂 Project Structure

Jupyter notebooks for model training and experimentation

Dataset preprocessing and evaluation scripts

🎯 Objective

To explore and apply deep learning techniques for gesture recognition and gain hands-on experience with CNN-based image classification.
